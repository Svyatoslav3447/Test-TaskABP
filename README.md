# Car Showroom

Car Showroom — це React-додаток для перегляду та фільтрації автомобілів у стилізованому інтернет-магазині. Проєкт демонструє базову роботу з React, TypeScript, React Router та компонентною архітектурою.

Посилання на розгоронутий застосунок: https://svyatoslav3447.github.io/Test-TaskABP/

## Особливості

- Перегляд featured автомобілів на головній сторінці
- Пошук автомобілів за назвою
- Фільтрація за брендом, тегами та сортуванням
- Сторінка деталей автомобіля
- Сторінка улюблених авто та сторінка "Про нас"
- Адаптивний інтерфейс з сучасним UI

## Технології

- React 19
- TypeScript
- Vite
- React Router DOM
- ESLint

## Встановлення

1. Перейдіть у папку проєкту:
   ```bash
   cd car-showroom
   ```
2. Встановіть залежності:
   ```bash
   npm install
   ```

## Запуск проєкту

Розробницький режим:
```bash
npm run dev
```

Після цього відкрийте у браузері:
```text
http://localhost:5173
```

## Доступні команди

- `npm run dev` — запуск локального сервера розробки
- `npm run build` — збірка проєкту для продакшену
- `npm run preview` — попередній перегляд зібраної версії
- `npm run lint` — перевірка коду ESLint

## Структура проєкту

```text
src/
  api/            # API-логіка для роботи з даними
  components/     # UI-компоненти
  pages/          # Сторінки додатку
  styles/         # CSS-стилі
  types/          # TypeScript-типи
  App.tsx         # Основний роутинг
  main.tsx        # Точка входу
```
